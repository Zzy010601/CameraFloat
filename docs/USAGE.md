# 使用说明

本文覆盖 macOS 原生版（`CameraFloat.app`）与 Windows / 跨平台版（`windows/camera_float.py`）。两版功能一致，操作对应关系见文末对照表。

---

## 1. 启动与权限

### macOS

```bash
./build.sh
open CameraFloat.app
```

首次启动系统弹窗请求摄像头权限，点「允许」。若误点拒绝，小窗内会显示「打开系统设置」按钮，可直接跳到 系统设置 → 隐私与安全性 → 摄像头。

### Windows

双击 `windows\run.bat`（首次会自动建虚拟环境并装依赖），或：

```powershell
cd windows
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw camera_float.py
```

Windows 首次调用摄像头时，系统设置 → 隐私和安全性 → 相机 需要允许「桌面应用访问你的相机」。

## 2. 窗口操作

窗口是无边框的，所有操作都靠鼠标命中位置判断。

| 操作 | 效果 |
|---|---|
| 拖动窗口四边 / 四角 | 调整窗口大小（12～14pt 热区，光标随边缘变化） |
| 拖动画面 | 取决于当前「拖动模式」：平移取景 / 移动窗口 |
| `⌘`(mac) / `Ctrl`、`Alt`(win) + 拖动 | 任何模式下都临时移动窗口 |
| 滚轮 / 双指捏合 | 以光标位置为锚点缩放画面（1～6 倍） |
| `⌘`(mac) / `Ctrl`(win) + 滚轮 | 缩放窗口本身（保持右边缘与垂直中心） |
| 双击画面 | 复位取景 |
| 右键（Windows 版） | 打开配置菜单 |

窗口尺寸限制：最小 90×90，最大宽度 1600。

**为什么拖画面不拖窗口？**
因为默认「拖动模式」是「拖动画面视角」，这样才能像画布一样挪取景。想直接拖窗口，点一下画面中央那个圆形按钮切到「拖动整个窗口」，或按住 `⌘`/`Ctrl` 拖动。

---

## 3. 取景：平移与缩放

画面在整个窗口内的位置由三部分决定：

1. **基准尺寸**：按当前贴合方式算出「画面铺满窗口（或完整放进窗口）」时的大小
2. **缩放倍数** `zoom`：1.0 ～ 6.0
3. **平移偏移** `pan`：相对基准位置再叠加的位移

任何缩放倍数下画面都不会露出黑边（选「自适应」除外，那个模式本来就是letterbox）。

缩放锚点算的是「光标下的画面相对坐标」，缩放前后那一点的内容固定在原地，这才是画布缩放手感的关键，而不是简单居中放大。

`⌘0` / `Ctrl+0` 或双击画面可复位到 `zoom=1.0`、右对齐。

---

## 4. 四种贴合方式

窗口长宽比和摄像头画面长宽比几乎不可能刚好一致，多出来的差异按下面的方式处理：

| 方式 | 行为 | 适用场景 |
|---|---|---|
| **右固定（裁左边）** | 画面高度铺满，右边缘钉住窗口右边缘，左边被裁掉 | 默认。窗口压窄时右侧视角不动，最适合盯右后方 |
| **左固定（裁右边）** | 左边缘钉住，右边被裁 | 画面主体在左侧时 |
| **居中裁切** | 两边同时裁，画面居中 | 常规居中取景 |
| **自适应（完整显示）** | 整幅画面完整可见，多余部分留黑边 | 需要看全画面、不接受裁切时 |

裁切的力度由窗口宽高比决定：

```
可见比例 ≈ 窗口宽度 ÷ (窗口高度 × 画面宽高比)
```

以 1080p 画面（16:9）为例，窗口高度 200、宽度压到 90 时，横向只剩约 1/4 的画面宽度。

## 5. 镜像（后视镜）

开启后画面左右翻转，抬手的方向和画面里的方向一致，这就是后视镜的观感。

入口：

- macOS：菜单栏「配置 → 镜像画面（后视镜）」
- Windows：右键菜单 / 托盘菜单 → 镜像画面（后视镜）

默认开启。看自己时开着更自然，看文字（如白板、门牌）时建议关掉。

---

## 6. 摄像头源

| 平台 | 可选设备 |
|---|---|
| macOS | 内置摄像头、外接 USB 摄像头、iPhone 连续互通相机、桌上视角相机 |
| Windows | 内置 / USB 摄像头、虚拟摄像头（OBS Virtual Camera 等） |

设备热插拔后菜单会自动刷新；当前设备被拔掉时会提示，可重新选择。

### 用 iPhone 当后视镜（macOS）

1. iPhone 升级到 iOS 16+，与 Mac 登录同一 Apple ID、连同一 Wi-Fi、双方蓝牙打开
2. iPhone **横放、锁屏、固定不动**（连续互通相机只在锁屏静止时上线）
3. 镜头朝你的右后方，用支架或夹在椅背 / 书架上
4. 「配置 → 摄像头源」选择你的 iPhone
5. 保持镜像开启

延迟约 0.1～0.2 秒。

## 7. 置顶与隐藏

- **置顶**：控制条的图钉按钮，或在菜单里切换。默认关闭，即窗口会被其它窗口盖住，需要时再钉住
- **隐藏窗口**：控制条 × 按钮、`Esc`、`⌘W` / `Ctrl+W`；隐藏后摄像头仍在运行，从菜单栏图标（macOS）或托盘图标（Windows）可唤回
- **退出**：`⌘Q` / `Ctrl+Q`，或菜单「退出」

## 9. 状态持久化

以下状态会写入系统偏好并在下次启动时恢复：

- 窗口位置与尺寸
- 画面缩放倍数与平移偏移
- 镜像开关
- 置顶开关
- 贴合方式
- 拖动模式
- 当前摄像头设备

macOS 存在 `~/Library/Preferences/com.local.camerafloat.plist`（`defaults read com.local.camerafloat` 可查看）。
Windows 存在注册表 `HKCU\Software\CameraFloat\CameraFloat`。

重置全部状态：

```bash
# macOS
defaults delete com.local.camerafloat
```

```bat
:: Windows
reg delete "HKCU\Software\CameraFloat" /f
```

## 10. 常见问题

**Q：内置摄像头能不能拍身后？**
不能。笔记本内置摄像头物理固定在屏幕顶端、只朝正前方，纯软件无法改变朝向。要用后视镜效果必须换摄像头源（iPhone 连续互通相机 / 外接 USB 摄像头）。

**Q：画面有水印、红心、背景虚化？**
那些是 macOS 系统级「视频效果」（控制中心里的绿色摄像机图标），处理发生在系统摄像头管线上，任何 App 拿到的都是加过特效的画面。关掉「人物居中」（它会让画面缓慢平移追踪人脸，后视镜场景下视角会乱飘）、「人像」、「回应」即可。

**Q：点一下小窗，macOS 顶部菜单栏就变成应用名了？**
这是常规应用（有 Dock 图标）的固定行为。不想要的话可以把 `setActivationPolicy(.regular)` 改成 `.accessory` 并加 `LSUIElement`，代价是失去 Dock 图标。

**Q：窗口跑到屏幕外找不到了？**
程序启动时会校验保存的位置，至少保留 80×60 在可见区域内，否则回到默认位置。若仍异常，删除偏好重置即可。

**Q：Windows 版双击没反应？**
用命令行跑 `python camera_float.py` 看报错。常见原因：Python 未加入 PATH、缺少 PySide6、或杀软拦截。也可检查 `python -c "import PySide6"`。

**Q：Windows 版能开机自启吗？**
把 `CameraFloat.exe` 的快捷方式放进 `shell:startup` 目录（`Win+R` 输入 `shell:startup`）。

## 11. 两版差异

| 项目 | macOS 原生版 | Windows 跨平台版 |
|---|---|---|
| 技术栈 | Swift + Cocoa + AVFoundation | Python + PySide6 + QtMultimedia |
| 界面 | 原生 NSWindow，14pt 圆角 | QWidget 无边框窗口，自绘 |
| 菜单 | 顶部菜单栏 + 状态栏菜单 | 托盘菜单 + 右键菜单 |
| 摄像头 | AVFoundation | Qt Media Foundation / FFmpeg 后端 |
| 打包 | `./build.sh` → `.app` | `build.bat` → 免安装目录 |
| 快捷键 | `⌘` 系 | `Ctrl` 系 |
